AiRM – AI Resource Manager

Rust project to improve AI training workload on various platforms.

Introduction
Experimenting project in the area of resource management for AI workloads using Rust language on Fedora Linux.

Current state
🚧 In progress
- Project structure and setup

Technologies
- Language: Rust
- OS: Fedora Linux
- Build: Cargo

How to Use
Requirements: Rust, Cargo

Compilation and Execution
git clone https://github.com/Sachhin-s-kumar/AiRM.git
cd AiRM
cargo build
cargo run

Testing
cargo test

Project Goals
Research in resource management, optimization and AI workloads; project will change with development of Rust language.
